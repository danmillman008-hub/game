# تولید تصویر با مدل ویدیو — آزمون شد، کار می‌کند

> ایدهٔ تو: «از خود مدل ویدیو برای تولید تصویر استفاده کن؛ یک کانواس خالی بده،
> پرامپت بده، تصویر را از داخلش دربیار.» — اجرا کردم. **درست بود** و درِ بستهٔ
> تصویرساز را باز کرد.

## روش

```
کانواس خالی (۹۶۰×۱۲۸۰، بدون هیچ شکل)  →  مدل ویدیو + پرامپت کامل صحنه
                                        →  فریم ۰ = کی‌فریم
                                        →  فریم آخر = همان شات، ۴ ثانیه
```

هیچ کامپوزیت، هیچ برش، هیچ ماسکی. کانواس فقط یک گرادیان یا کاغذ خالی است —
عمداً بدون هیچ شکلی، چون هر شکلی را مدل «توضیح» می‌دهد و تبدیل به شیء می‌کند.

| کانواس | چه چیزی برای مدل مناسب است |
|---|---|
| `dusk.png` | گرادیان آبی→نارنجی، برای نمای بیرونی |
| `night.png` | تقریباً مشکی با چند ستاره، برای شب |
| `paper.png` | کرم روشن، برای کلوزآپ و اینتریور |

## نتیجه — ۴ شات، ۵۵ تا ۹۷ ثانیه هر کدام

| شات | خروجی | حکم |
|---|---|---|
| `art_plain` (دشت و جادهٔ غروب) | آسمان با ابر، درخت‌های سیلوئت، جاده با خط سفید و انعکاس، کاراکتر با کت قرمز | ⭐ **پس‌زمینهٔ آمادهٔ تولید** |
| `art_knight` (بانوی زره‌پوش با نیزه) | زره با ستارهٔ قرمز، نیزه، چراغ سقفی، سنگ‌فرش، صورت انیمه‌ای | ⭐ **آرت کاراکتر** |
| `art_room` (اتاق خالی) | پنجرهٔ قوسی، میز، صندلی با پارچه، نور | ⚠️ شبیه **نقاشی رنگ‌روغن**، نه سل |
| `art_face` (کلوزآپ صورت) | صورت با سایه‌زنی نرم و حجم | ❌ **۳بعدی/نیمه‌واقعی شد** |

مقایسهٔ تصویری: `films/anime_ten/qc/artgen_pipeline.jpg`

و بعد از آن، از همان آرتِ تولیدشده زنجیره گرفتم:

| شات | نتیجه |
|---|---|
| `art_k2` از فریم آخر `art_knight` | نمای باز از همان دروازه، همان زن، همان چراغ — **مکان و کاراکتر حفظ شد** |
| `art_plain2` از فریم آخر `art_plain` | Close روی همان مرد از پشت، همان جاده |

## چیزی که یاد گرفتیم (و دوباره عدد دارد)

1. **نمودار رنگی کانواس، ترکیب‌بندی نهایی را تعیین می‌کند.** کانواس غروب →
   آسمان نارنجی؛ کانواس شب → دروازهٔ تاریک با چراغ. مدل رنگ کانواس را به ارث می‌برد
   و بافت می‌سازد. پس کانواس یک «راهنمای نور» است، نه یک صفحهٔ خالی.
2. **صورت کلوزآپ، ضعیف‌ترین نقطه است.** از کانواس کاغذی، مدل یک صورت **۳بعدی با
   سایه‌زنی نرم** ساخت — نه سل. برای کلوزآپ باید «آنکر» بدهی (یک فریم سل موجود)
   و از آن زنجیره کنی، نه از کانواس خالی.
3. **اینتریور بدون کاراکتر، به رنگ‌روغن می‌رود.** بدون سوژه، مدل بافت می‌سازد.
   راه‌حل: همیشه یک عنصر کاراکتری یا یک منبع نور سخت در پرامپت باشد.

## خط تولید جدید (جایگزین کامپوزیت PIL)

```
کانواس + پرامپت  →  آرت (پس‌زمینه / کاراکتر / اینسرت)
آرت  →  زنجیره: شات بعدی از فریم آخر
آرت  →  آپ‌اسکیل ۴× (studio/toolbox/upscale.py) اگر لازم شد
```

مزیت بزرگ: **هر تصویر یک نقاشی یکپارچه است**، پس مدل در شات بعد چیزی برای ترمیم
ندارد و کل انرژی‌اش صرف حرکت می‌شود — همان دلیلی که خلبان اول شکست خورد.

## اجرا

```bash
python3 studio/artgen.py canvas                     # سه کانواس
python3 studio/artgen.py jobs studio/motions/art_prompts.json
printf 'films/short16/gen_jobs_art.json\\n' > .mivi-trigger
python3 studio/artgen.py extract                    # فریم ۰ و فریم آخر -> films/anime_ten/art/
```

## هزینه

هر آرت = یک تولید ویدیو (۵۵–۹۷ ثانیه رانر). یعنی ساخت **پس‌زمینه‌های فیلم** تقریباً
هم‌قیمت خود شات‌ها است، ولی نتیجه دو برابر است: هم کی‌فریم داری، هم یک شات ۴ ثانیه‌ای.
