# هویت کاراکتر — تشخیص، شاهد، و مسیر درست

> ایراد تو: «ویدیوهایت کاراکتر یکسان نداشتند، دوست من، ایرادت زیاد است.»
> درست بود، و علتش یک تصمیم معماری در همین ریپو بود، نه ضعف پرامپت.

## ۱. تشخیص — چرا چهره‌ها عوض می‌شدند

در سند `HOUSE_STYLE.md` نوشته بودیم «لنگر وسط کادر، بدون تغییر ژست» و برد ۶ از ۱۶
گرفتیم. اما هر لنگر انیمه از **کانواس خالی** نقاشی می‌شد:

```
films/anime_ten/canvas/{dusk,night,snow,paper}.png   ← مستطیل گرادیانی
        ↓ artgen.py jobs
   یک still که مدل از صفر نقاشی می‌کند
```

هر still یک **اختراع تازه** است. یعنی نگهبانِ چپِ نمای دو نفره و نگهبانِ چپِ کلوزآپ،
دو مرد مختلف‌اند. مدل کارش را درست انجام داده؛ چیزی که باید هویت را حمل کند، وجود نداشت.

اثبات در یک نگاه: `films/anime_ten/qc/ab_cast.jpg` (چپ = کانواس خالی، راست = compose).

## ۲. ابزاری که داشتیم و استفاده نمی‌کردیم

`bridge/mivi_mcp.py` از روز اول این را داشته:

```python
("mivi_compose", "Image + image + prompt -> one new image (Mivi's composer). Needs >=2 images.")
```

و فیلم قبلی (`films/before_leaving/.probe/probe.py`) **همهٔ کلوزآپ‌هایش** را همین‌طور
ساخته بود: `s04_raha_cu` = compose(`master_wide.png`, `ref_raha.png`) + پرامپت.
خط انیمه اما از کانواس شروع شد و این مسیر رها ماند.

## ۳. A/B اندازه‌گیری‌شده (۲۰۲۶-۱۰-۳۱، ۱ کردیت)

| | روش | نتیجه |
|---|---|---|
| چپ | کانواس خالی + پرامپت کامل | چهرهٔ تازه، موی سیاه، زرهٔ متفاوت → «آدم دیگری» |
| راست | `compose` (نمای دو نفره + کلوزآپ قدیمی به‌عنوان pose ref) | همان دو نگهبان، همان زره، ولی **کل قاب قفل شد**: هیچ بزرگ‌نمایی نداد |

**نتیجهٔ صادقانه:** `compose` هویت را می‌آورد، ولی **کنترل کادربندی را از دست می‌دهد**.
پرامپت «close-up» را نادیده گرفت و همان نمای دو نفره را با جزئیات بهتر برگرداند.

یعنی مسیر درست این است:

```
compose برای ساختن «شیت کاراکتر» و «لنگرهای ثابت»  →  بعد I2V روی همان لنگر
نه: compose برای هر فریم
```

## ۴. دستور کار — پنج قدمی که از متدولوژی گرفته‌ام

از `cclank/lanshu-awesome-ai-video-kit`، `methodology/15-seedance-masterclass.md` و
`20-realistic-character-consistency.md` (اصطلاحات: Character Sheet، Omni Reference):

| قدم | کار | ابزار ما |
|---|---|---|
| ۱ | یک **master** از هر کاراکتر (بهترین شات تا امروز) | `w_two_src.png` برای نگهبان چپ |
| ۲ | شیت چندزاویه از همان master (روبه‌رو، نیم‌رخ، تمام‌قد) | `studio/cast.py sheet --master …` |
| ۳ | از شیت، لنگرهای تک‌نفره بساز (این بار کادربندی هم قابل کنترل) | `cast.py still --pose <شیت>` |
| ۴ | روی هر لنگر یک شات I2V (قواعد `HOUSE_STYLE.md`) | `make shot` |
| ۵ | هر بار لباس/زره عوض شد، **شیت را از نو بساز** | همان |

قاعدهٔ سختِ خودشان که با دادهٔ ما جور است: **بیش از ۳ کاراکتر در یک shot = خطا**،
و برای ما حتی ۲ کاراکتر با حرکت = بازسازی (take ۲۵).
