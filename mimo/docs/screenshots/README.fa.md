# فهرست اسکرین‌شات‌های لازم (اجرا نشده در این محیط)

وضعیت: **BLOCKED_BY_ENVIRONMENT** — در محیط ساخت هیچ مرورگر headless (Chromium/Firefox) نصب نیست و دریافت آن از
CDN بیرون از دسترس است. برای همین هیچ اسکرین‌شاتی جعل یا از اینترنت برداشته نشده است.

## چگونه بگیرید

```bash
./mimo/start-preview.sh          # سپس http://localhost:4000
```

در مرورگر، عرض پنجره را به حالت موبایل (۳۹۰×۸۴۴) بگذارید و این ۶ نما را ذخیره کنید:

| # | نما | مسیر | چه چیزی باید دیده شود |
|---|---|---|---|
| 1 | یادگیری | `/` (زبانهٔ یادگیری) | مسیرهای نمونه، پیشرفت، متن فارسی، RTL |
| 2 | درس تعاملی | `/` → یک درس | تعامل، دکمهٔ بررسی، بازخورد فارسی |
| 3 | تمرین و آزمون | زبانهٔ «تمرین و آزمون» | رابط EPM با برچسب‌های فارسی، همهٔ آیتم‌های ناوبری |
| 4 | آزمون در جریان | EPM → آزمون آزمایشی | ۴ گزینه با برچسب A/B/C/D |
| 5 | مکس | زبانهٔ «مکس» | LearnHarness در iframe، گراف/تنظیمات |
| 6 | جدایی داده | `http://localhost:4000/api/preview/status` | JSON با سه موتور `ok` |

نام پیشنهادی: `docs/screenshots/01-learn.png` … `06-status.png`.
