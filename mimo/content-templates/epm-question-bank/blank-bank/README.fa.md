# بستهٔ خالی ESQ

این پوشه اسکلت یک بستهٔ `.esq` است. ساده‌ترین راه، ساختن بسته از CSV است:

```bash
python3 ../tools/build_esq.py ../data/example-questions.csv ../example-bank/my-bank.esq
```

اگر می‌خواهید بسته را دستی بسازید، سه فایل زیر را پر کنید و سپس همه را در یک ZIP با پسوند `.esq` بگذارید.
