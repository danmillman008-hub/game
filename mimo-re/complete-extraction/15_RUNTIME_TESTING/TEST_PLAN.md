## ۴. روش اجرا (وقتی دستگاه موجود شد)

```bash
adb install -r Mimo_9.35.apk
adb logcat -c && adb logcat > logs/run01.log &
adb shell am start -n com.getmimo/.ui.SplashActivity_default
# per journey: adb shell screenrecord + screenshot at key states
adb shell dumpsys activity top | grep mResumedActivity
adb shell am force-stop com.getmimo   # killed-process tests
adb shell cmd connectivity airplane-mode enable
```
هر خروجی در `screenshots/NN_<surface>_<state>.png` و `logs/runNN.log`، و ردیف متناظر در
`MASTER_TEST_COVERAGE.csv` با `VERIFIED_RUNTIME`.
