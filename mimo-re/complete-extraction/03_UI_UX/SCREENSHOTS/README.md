# اسکرین‌شات‌ها — هیچ تصویری جعل نشده است

در این محیط نه emulator، نه adb و نه دستگاه مجاز وجود دارد؛ بنابراین **هیچ اسکرین‌شاتی گرفته نشده
و هیچ تصویری تولید نشده است**. وضعیت: `NOT_TESTED` / `NOT_ACCESSIBLE`.

برای تکمیل: روی دستگاه آزمایشی مجاز، ۲۴ سفر بخش ۱۵ را اجرا کنید و با این نام‌گذاری ذخیره کنید:
`NN_<surface>_<state>.png` (مثال: `03_onboarding_motive_selected.png`).
هر تصویر باید در `MASTER_EVIDENCE_DATABASE.csv` با `evidence_type=SCREENSHOT` و
`verification_status=VERIFIED_RUNTIME` ثبت شود.
