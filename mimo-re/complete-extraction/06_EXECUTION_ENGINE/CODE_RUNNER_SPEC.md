# ۰۶ج — مشخصات اجراکنندهٔ کد درس

## ۱. دامنهٔ زبان‌ها (اندازه‌گیری‌شده در محتوا)

| زبان | فایل در درس کدی | اجرای محتمل |
|---|---|---|
| html/css | ۲,۲۶۳+ | پیش‌نمایش در WebView (`hasVisualOutput`) |
| javascript/jsx | بالا | موتور JS یا WebView |
| python | ۳,۱۵۵ | نیازمند مفسر (Chaquopy/Pyodide/سرور) |
| sql | ۶۹۴ | SQLite محلی + seed |
| swift | ۶۴۳ | **غیرقابل اجرا در اندروید** |
| typescript | ۲۴۳ | نیازمند transpile |
| bash | ۱۸۶ | **غیرقابل اجرا در اندروید** |

نکتهٔ مهم: وجود swift و bash در محتوا نشان می‌دهد Mimo **همهٔ** زبان‌ها را اجرا نمی‌کند؛
برای این دو، فقط تطبیق با `solvedContent` ممکن است (INFERRED, MEDIUM).

## ۲. قرارداد «درست بودن» (سه فرضیه، رتبه‌بندی‌شده)

| فرضیه | شاهد موافق | شاهد مخالف | رتبه |
|---|---|---|---|
| H1: سرور اجرا و تست می‌کند | `/v1/code/runfiles`، نبود تست در کلاینت | — | **MEDIUM-HIGH** |
| H2: کلاینت با `solvedContent` مقایسه می‌کند | `solvedContent` در همهٔ فایل‌ها | ۴۲ فایل null؛ مقایسهٔ متنی شکننده | MEDIUM |
| H3: کلاینت خروجی را با پیش‌بینی مقایسه می‌کند | `hasVisualOutput` | داده‌ای برای پیش‌بینی خروجی یافت نشد | LOW |

## ۳. طرح اجراکننده برای محصول مستقل

```
┌ Request {lessonId, files[], entry} ────────────────────────────┐
│ runner dispatcher (by language)                                │
│   html/css  → WebView sandbox (no network, no storage)         │
│   js/jsx    → QuickJS/WASM, 2s wall clock                      │
│   python    → Pyodide (WASM) یا سرویس ایزوله                    │
│   sql       → SQLite in-memory + bootstrapScript               │
│   other     → «اجرا پشتیبانی نمی‌شود» (صادقانه)                  │
└ 결과 {stdout, stderr, assertions[], verdict} ──────────────────┘
```
**الزامات:** بدون شبکه، بدون فایل‌سیستم پایدار، سقف زمان ۲s، سقف خروجی ۶۴KB،
تشخیص حلقهٔ بی‌پایان، و شمارش مصرف برای fairness.

## ۴. چیزی که Mimo ندارد و باید ساخته شود

| نیاز | دلیل |
|---|---|
| تست‌های قابل مشاهده برای کاربر | هیچ تستی در محتوا نیست ⇒ کاربر نمی‌داند چه چیزی سنجیده می‌شود |
| بازخورد diff | فقط pass/fail |
| اجرای محلی برای swift/bash | زبان‌های موجود در محتوا اجرا نمی‌شوند |
| اجرای آفلاین | اجرا نیازمند شبکه است (INFERRED) |
