# ۰۷و — موتور تمرین (Smart Practice)

## ۱. آنچه در داده هست

| شاهد | محتوا |
|---|---|
| فصل‌های `practiceLevel2/3` | ۵۲۷ فصل تمرین در کنار ۷۸۳ فصل درس |
| آموزش‌های تمرینی | `practiceRequired` ۱۵۷ + `practiceOptional` ۱۳۴ = ۲۹۱ آموزش |
| endpoint | `/v1/practice/statistics` (GET)، احتمالاً `/v1/practice/session` (**UNKNOWN**) |
| مودال‌ها | `SmartPracticeChargedModal`، `SmartPracticeMasteredModal` |
| رشته‌ها | `practice_*` (۳۶)، `smart_practice_*` |

## ۲. استنباط کارکرد (INFERRED، MEDIUM)

```
۱) سرور فهرست درس‌های «ضعیف» کاربر را برمی‌گرداند (احتمالاً بر پایهٔ خطاهای اخیر)
۲) کلاینت فصل‌های موجود را «بازخدمت» می‌کند (لینک به همان chapterId)
۳) اگر کاربر پولی نباشد: مودال Charged؛ اگر تسلط یافته باشد: مودال Mastered
۴) پایان جلسه: بازخورد + به‌روزرسانی آمار
```
شاهد پشتیبان: نبود شنوندهٔ id جدید برای تمرین و وجود `SmartPractice*Modal` + `practice_*`.

## ۳. قرارداد دادهٔ پیشنهادی (برای محصول جدید)

```json
{
  "sessionId": "uuid",
  "items": [{ "chapterId": 1, "reason": "recent_error", "errorCodes": ["SIGN"], "priority": 0.82 }],
  "budget": { "minutes": 10, "items": 8 },
  "stopRule": "retrievability_below_0.7"
}
```

## ۴. کمبودهای مشخص

| کمبود | اثر |
|---|---|
| Mimo دلیل انتخاب سؤال را به کاربر نمی‌گوید | انگیزهٔ کم |
| هیچ سنجهٔ درصد/تراز ندارد | برای کنکور بی‌فایده |
| بازخورد per-gap ندارد | تشخیص خطا ممکن نیست |
| تمرین = بازخدمت فصل، نه بانک سؤال | انتخاب محدود |

## ۵. الزامات موتور کنکور (تفاوت بنیادی)

1. **بانک سؤال مستقل** از محتوا با متادیتا (مبحث، سال، سختی، منبع، کلید).
2. **آزمون** با نمره، تراز، رتبهٔ تخمینی، تحلیل زمان.
3. **تشخیص خطا**: نگاشت گزینهٔ انحرافی → خطای رایج (Mimo: ۱۴,۸۷۰ گزینه بدون برچسب).
4. **مرور فاصله‌دار** روی سؤال، نه فصل.
