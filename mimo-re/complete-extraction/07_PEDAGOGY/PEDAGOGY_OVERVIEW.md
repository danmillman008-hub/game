# ۰۷ — مدل آموزشی Mimo (آنچه اثبات‌پذیر است)

**خلاصهٔ یک‌خطی:** Mimo یک سیستم «تمرین فشردهٔ کوتاه‌مدت» است، نه سیستم تسلط بلندمدت؛
سنجش آن **درون‌درسی و آنی** است و مدل دانش آن **سمت سرور و نامرئی** است.

## ۱. ساختار برنامهٔ درسی (اندازه‌گیری‌شده، VERIFIED_STATIC)

```
Track (19) ──► Section (249) ──► Tutorial (1,029) ──► Chapter (1,947) ──► Lesson (18,272)
                                    │                     │
                                    │ type                │ type = نقش/سختی
                                    └ course              └ practiceLevel1  (783 در course)
                                      practiceRequired      practiceLevel2  (174، فقط practiceRequired)
                                      practiceOptional      practiceLevel3  (353، فقط practiceOptional)
                                      guidedProject(±Opt)   challengeLevel0/1/2 (فقط challenges)
                                      challenges
```

**یافتهٔ کلیدی:** هیچ فصل «نظری» یا «آزمون» جدا وجود ندارد؛ **همهٔ ۱,۹۴۷ فصل از نوع تمرین‌اند**.
نقش آموزشی از «نوع آموزش» و «سطح فصل» مشتق می‌شود:

| نوع آموزش | فصل‌ها | تفسیر |
|---|---|---|
| `course` (۵۰۷) | practiceLevel1 | آموزش اصلی، تمرین پایه |
| `practiceRequired` (۱۵۷) | practiceLevel2 | تمرین اجباری (تثبیت) |
| `practiceOptional` (۱۳۴) | practiceLevel3 | تمرین اختیاری (تعمیق) |
| `guidedProject(Optional)` (۱۹۱) | L1/L3 | پروژهٔ هدایت‌شده |
| `challenges` (۴۰) | challengeLevel0/1/2 | چالش |

## ۲. ریتم درس (اندازه‌گیری)

| سنجه | مقدار |
|---|---|
| درس بر فصل | میانه ۱۰، میانگین ۹.۴، بیشینه ۲۸ |
| فصل تک‌درسی | ۶۷۰ از ۱,۹۴۷ (۳۴٪) |
| درس تعاملی | ۱۴,۲۴۸ (۷۸٪) |
| درس کدی | ۴,۰۲۴ (۲۲٪) |
| بلوک تعاملی در هر درس | ۱.۵۷ (۳۹,۰۶۵ بلوک / ۲۰,۳۰۶ سند) |
| نسبت جای خالی به سند | ۱.۴۳ |

⇒ درس‌ها **۲ تا ۵ دقیقه‌ای** طراحی شده‌اند (یک مفهوم، یک تعامل، بازخورد فوری). این انتخاب
«موفقیت سریع» است، نه «تسلط».

## ۳. آنچه واقعاً اثبات‌پذیر نیست

| ادعای رایج | وضعیت واقعی |
|---|---|
| «Mimo از تکرار فاصله‌دار استفاده می‌کند» | **UNKNOWN** — الگوریتم در سرور؛ تنها شاهد، `practiceLevel3` و «تمرین هوشمند» است |
| «مدل دانش‌آموز دارد» | **PARTIALLY_VERIFIED** — endpoint `/v1/practice/statistics` و صفحهٔ آمار وجود دارد، ولی مدل قابل استخراج نیست |
| «سطح‌بندی تطبیقی دارد» | **UNKNOWN** — `challengeLevel*` سختی محتواست، نه تطبیق فردی |
| «آزمون تعیین سطح دارد» | **UNKNOWN** — مسیر آنبوردینگ «هدف» می‌پرسد، نه سطح |

این تمایز برای کنکور حیاتی است: Mimo یک **تمرین‌باز** است؛ کنکور یک **آزمون‌باز**.
