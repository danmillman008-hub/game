# ۱۸ج — برنامهٔ انطباق (۳ فاز، قابل اجرا)

## فاز A — «اسکلت» (۸ هفته)
| خروجی | معیار پذیرش |
|---|---|
| مدل دادهٔ هدف (§17ب) + مهاجرت | اسکیمای مستقر |
| پارسر/رندرر درس با `math` و RTL | ۵۰ سؤال نمونه درست رندر |
| بانک سؤال ۲,۰۰۰ سؤالی (یک درس) | بررسی دوگانهٔ کلید |
| پیشرفت + outbox | کار در آفلاین |

## فاز B — «سنجش» (۸ هفته)
| خروجی | معیار پذیرش |
|---|---|
| آزمون زمان‌دار + نمرهٔ خام/درصد | ۱۰۰٪ صحت محاسبه |
| تراز و رتبهٔ تخمینی نسخهٔ ۱ | MAPE ≤ ۱۵٪ |
| نقشهٔ ضعف + تشخیص خطا | ≥ ۶۰٪ گزینه‌ها `error_code` دارند |
| مرور فاصله‌دار (FSRS) | صف ≤ ۲۰/روز، AUC ≥ ۰٫۷ |

## فاز C — «مزیت» (۸ هفته)
| خروجی | معیار پذیرش |
|---|---|
| مربی فارسی با حفاظ | ۲۰ حملهٔ تزریق رد شود |
| گزارش والد/معلم | هفتگی + قابل اشتراک |
| آزمون شبیه‌سازی کامل + تحلیل زمان | خروجی PDF/تصویر |
| پنل تألیف + انتشار نسخه‌دار | انتشار بدون انتشار اپ |

## وابستگی بحرانی (Critical path)

```
مدل داده → پارسر/رندرر → بانک سؤال → آزمون → تراز → تحلیل
                                ↘ مرور فاصله‌دار
                                ↘ مربی
```
**ریسک اصلی مسیر بحرانی:** اعتبار «تراز». بدون دادهٔ تاریخی، تراز فقط تخمین نسبی است.
راه‌حل: شروع با «درصد» و افزودن تراز پس از ۵,۰۰۰ آزمون واقعی.

## آنچه از Mimo گرفته می‌شود (مرز صریح)

| گرفته می‌شود | گرفته نمی‌شود |
|---|---|
| ساختار DSL و الگوریتم تصحیح آفست | متن/درس/تصویر/برند Mimo |
| الگوی outbox و مدل نسخه‌دار | کد جاوا/کاتلین |
| مدل Track→Section→Tutorial→Chapter→Lesson | کلید/استریک/۹ نقطهٔ پی‌وال |
| ۹ قاعدهٔ پرامپت (بازنویسی فارسی) | پرامپت لفظ‌به‌لفظ |
| الگوی ۱۲ گامی آنبوردینگ | متن گام‌ها |

این مرز، الزام قید مأموریت (عدم بازتولید محتوای اختصاصی) را رعایت می‌کند.
