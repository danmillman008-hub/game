# ۱۱ج — سیاست کش

## ۱. کش‌ها

| کش | محل | شاهد |
|---|---|---|
| بستهٔ محتوا | assets | ۱۰,۳۰۴ فایل JSON |
| پیشرفت ارسال‌نشده | Room (`in_queue`) | رشتهٔ DELETE |
| تنظیمات/پرچم | DataStore | ۱۴۸ کلاس |
| client-config | حافظه | `/v2/client-config` |
| تصاویر | نامعلوم (Glide مشاهده نشد) | **UNKNOWN** |
| گفتگوی مربی | سرور | `conversationId` |

## ۲. معماری «همهٔ محتوا در APK»

| مزیت | عیب |
|---|---|
| صفر تأخیر و آفلاین کامل | ۱۴۲MB برای ۱۰ زبان |
| بدون CDN | هر تغییر = انتشار APK |
| ساده | برای بانک سؤال بزرگ مقیاس‌ناپذیر |

**پیشنهاد برای کنکور:**
```
/v1/content/manifest → {version, packs:[{id,bytes,sha256,url,deltaFrom}]}
دانلود → SQLite (جدول questions + ایندکس FTS5) → جستجو و آفلاین
```
