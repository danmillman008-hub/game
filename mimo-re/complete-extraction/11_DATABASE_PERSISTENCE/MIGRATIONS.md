# ۱۱ه — مهاجرت و سازگاری

| موضوع | وضعیت | شاهد |
|---|---|---|
| کلاس `Migration` در بسته | ❌ یافت نشد | جستجوی `CLASS_INDEX` |
| `fallbackToDestructiveMigration` | احتمال بالا | نبود Migration ⇒ INFERRED MEDIUM |
| نسخهٔ DB | نامعلوم | — |
| نسخهٔ محتوا در رکورد | ✅ دو فیلد | `tutorial_version`, `publish_set_version` |

**ریسک:** بدون Migration، به‌روزرسانی اپ می‌تواند پیشرفت ارسال‌نشده (`in_queue=1`) را حذف کند.
با توجه به «حذف پس از ارسال»، این داده قابل بازسازی نیست.

## الزامات محصول هدف

| نیاز | طرح |
|---|---|
| مهاجرت صریح | `MIGRATION_1_2` … + تست مهاجرت با دادهٔ نمونه |
| دادهٔ کاربر ابدی | هرگز `destructive` در تولید |
| نسخه‌داری سؤال | `questionVersion` + `answerKeyVersion` |
| پشتیبان | export/import + همگام‌سازی سرور |
| سازگاری عقب | حداقل ۶ ماه پشتیبانی نسخهٔ قدیم (`X-Min-Client-Version`) |
