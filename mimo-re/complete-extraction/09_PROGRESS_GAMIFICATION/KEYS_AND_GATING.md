# ۰۹د — کلیدها و دروازه‌گذاری

## ۱. شواهد

| شاهد | متن/معنا |
|---|---|
| `keys_left_today = "%d keys left today"` | شمارش روزانه |
| `keys_left_today_subtitle` | «از کلید برای باز کردن درس استفاده کن» (بازگویی) |
| `keys_zero_subtitle` | «کلیدهای جدید فردا می‌رسند» |
| `keys_unlimited_keys_pro_subtitle` / `max_*` | نامحدود با Pro/MAX |
| `/v1/user/keys`, `/v1/user/keys/consume` | مصرف سمت سرور |
| `keys_*` (۲۶ رشته) | صفحهٔ کلید و CTA |

## ۲. مدل استنباطی دروازه

```
درس → اگر باز است: اجرا
      اگر قفل: نمایش مودال کلید (تعداد باقی‌مانده) → مصرف ۱ کلید → باز شدن
      اگر کلید صفر: پیشنهاد ارتقا یا «فردا برگرد»
```
کلید دروازهٔ **درس** است، نه محتوا (INFERRED، MEDIUM).

## ۳. ارزیابی برای کنکور

| جنبه | Mimo | کنکور |
|---|---|---|
| دروازهٔ درس | ✅ کلید | ❌ نباید باشد (دسترسی آموزشی) |
| دروازهٔ ویژگی | ✅ Pro/MAX | ✅ تحلیل عمیق، آزمون‌های ویژه |
| دروازهٔ تمرین | ✅ (SmartPractice) | ✅ آزمون شبیه‌سازی دوم به بعد |
| آزاردهندگی | بالا (کلید روزانه) | باید صفر باشد برای محتوای پایه |

## ۴. توصیهٔ صریح

کلید را از «درس» بردارید؛ در عوض:
1. دسترسی به **بانک سؤال کامل** آزاد.
2. **تحلیل تشخیصی پیشرفته** (نقشهٔ ضعف، پیش‌بینی تراز) پولی.
3. **آزمون شبیه‌سازی نامحدود** پولی، آزمون اول رایگان.
