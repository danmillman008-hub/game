# ۰۹ب — XP، سطح و روزهای فعال

## ۱. شواهد عددی/متنی

| مفهوم | شاهد | مقدار |
|---|---|---|
| XP | `xp_*` رشته‌ها، `DailySparksGoalProgressView` | هدف روزانه |
| روزهای فعال | `dailySparks`, «Sparks» | شمارش روز |
| متن ۴۲sp | `daily_goal_*` | عدد بزرگ روی کارت |
| سطح | `level_*` رشته‌ها | **PARTIALLY_VERIFIED** |

## ۲. مدل استنباطی XP

```
xp(lesson_completed)  = ثابت پایه (نامعلوم)
xp(chapter_finished)  = پاداش بزرگ‌تر
xp(streak_kept)       = پاداش روزانه
goal(daily)           = کاربر در آنبوردینگ انتخاب می‌کند (۵/۱۰/۱۵/۲۰ دقیقه)
```
هیچ فرمول عددی در بسته نیست ⇒ اعداد **پیشنهادی** در بخش ۱۷ آمده‌اند، نه ادعای Mimo.

## ۳. طرح پیشنهادی برای کنکور

| رویداد | XP | دلیل |
|---|---|---|
| پاسخ درست سطح ۱ | ۱۰ | پایه |
| پاسخ درست سطح ۳ | ۲۰ | سختی |
| آزمون کامل | ۵۰ + ۰.۵×درصد | کیفیت |
| مرور فاصله‌دار درست | ۱۵ | تثبیت |
| ۷ روز متوالی | ۷۰ | تعهد |
| شکستن زنجیره با «محافظ» | ۰ (فقط محافظ مصرف) | نرم‌سازی |

معیار اصلی محصول هدف نباید XP باشد، بلکه **تراز/درصد** است. XP فقط لایهٔ انگیزشی است.
