# ۰۹ج — مدل زنجیره (Streak)

## ۱. شواهد

| شاهد | معنا |
|---|---|
| `MimoStreakWidget` + `StreakWidgetRefreshWorker` | ویجت و به‌روزرسانی پس‌زمینه |
| `StreakChallengeSheet`, `streak_challenge_prompt_accept = "Accept for %d"` | **چالش زنجیره با هزینه** |
| `streak_calendar_*`, `streak_calendar_height 324dp` | تقویم ۷ روزه/ماهانه |
| `streak_freeze`, `streak_repair` (رشته‌ها) | محافظ و ترمیم |
| `ArcProgressView` | نمایش کمانی پیشرفت |
| `daily_goal_*`, `Sparks` | هدف روزانه |

## ۲. مدل استنباطی

```
streak = تعداد روزهای متوالی با ≥۱ درس کامل‌شده (در منطقهٔ زمانی کاربر)
freeze: قابل خرید/دریافت؛ روز غایب را «پوشش» می‌دهد
repair: بازگرداندن زنجیرهٔ شکسته (پولی یا کلید)
challenge: «اگر X درس در Y ساعت تمام کنی، زنجیره حفظ می‌شود» با هزینهٔ %d
```
* «Accept for %d» ⇒ مبلغ/هزینهٔ عددی در رشته است (پول یا کلید) — **UNKNOWN** کدام.
* منطقهٔ زمانی: `org.joda` در بسته ⇒ محاسبه محلی با joda؛ قواعد سرور **UNKNOWN**.

## ۳. ریسک‌های طراحی (کپی نکنید)

| ریسک | چرا |
|---|---|
| فشار روانی («زنجیره‌ات می‌شکند») برای دانش‌آموز کنکور | اضطراب آزمون |
| چالش با هزینهٔ پولی | اخلاقی/انگیزشی |
| ویجت با یادآوری دائمی | تمرکز را می‌شکند |
| «Sparks» متریک ساختگی | انگیزهٔ بیرونی جای یادگیری |

## ۴. جایگزین پیشنهادی

| مفهوم Mimo | جایگزین برای کنکور |
|---|---|
| streak روزانه | «برنامهٔ هفتگی» با ۲ روز استراحت برنامه‌ریزی‌شده |
| freeze/repair | بازبرنامه‌ریزی خودکار (بدون جریمه) |
| چالش زنجیره | «آزمون کوتاه ۵ سؤالی» |
| Sparks | زمان مطالعه + تعداد سؤال + تراز |
