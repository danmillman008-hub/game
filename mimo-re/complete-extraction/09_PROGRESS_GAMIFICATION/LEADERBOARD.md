# ۰۹ه — لیدربورد و رقابت

## ۱. شواهد

| شاهد | معنا |
|---|---|
| `/v1/leaderboards/latest`, `/latest`+`friends`, `/{id}/userrank` | سه نما: عمومی، دوستان، رتبهٔ من |
| `LeaderboardSettingsActivity` | تنظیمات (نمایش/عدم نمایش) |
| `leaderboard_league_header_height 144dp`, `iap_podium_*` | لیگ و سکو |
| `ObserveUserLeaderboardResult → Leaderboard` (۳۶ یال) | MVI با observe |
| رشته‌های `league_*`, `leaderboard_*` | لایهٔ UI |

## ۲. مدل استنباطی

```
لیگ هفتگی (پیش‌فرض) → گروه ~۳۰ نفره → رتبه بر اساس XP هفته
پایان هفته: ارتقا/تنزل لیگ + پاداش
نماها: کلی، دوستان، رتبهٔ من
تنظیمات: شرکت نکردن / مخفی کردن نام
```

## ۳. ارزیابی

| جنبه | Mimo | کنکور |
|---|---|---|
| معیار رقابت | XP (کمیت) | درصد/تراز (کیفیت) |
| خطر | رقابت بی‌فایده، تقلب ساده | رتبه‌بندی باید با نمرهٔ آزمون باشد |
| بهترین کاربرد | انگیزهٔ روزانه | «رتبهٔ تخمینی کنکور» — بسیار انگیزشی |
| حریم خصوصی | تنظیمات دارد ✅ | همان |

## ۴. طرح پیشنهادی

* **لیگ مطالعه** (زمان + تعداد سؤال) برای انگیزه، به‌صورت اختیاری.
* **رتبهٔ تخمینی کشور** بر اساس آزمون‌های شبیه‌سازی — هستهٔ ارزش محصول کنکور.
* هرگز XP را با «درصد درست» مخلوط نکنید.
