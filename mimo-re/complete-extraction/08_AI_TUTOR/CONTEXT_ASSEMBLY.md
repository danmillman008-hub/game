# ۰۸ج — مونتاژ زمینه (Context assembly)

## ۱. اجزای زمینه (بازسازی‌شده)

| جزء | منبع | در کدام حالت | حساسیت |
|---|---|---|---|
| نام فایل درس | `SystemMessage(pathName)` | هر دو | کم |
| دستور درس | `instructions` (Markdown) | کدی | کم |
| کد هدف | `solvedContent` | کدی | **متوسط** (لو رفتن پاسخ) |
| کد فعلی کاربر | `UserMessage(codeFiles)` | کدی | کم |
| زمینهٔ درس تعاملی | `lessonContext` | تعاملی | **متوسط** (شامل پاسخ درست است!) |
| پرسش کاربر | `userMessage` | هر دو | کم |
| تاریخچه | سرور (`conversationId`) | ادامه | — |

**ریسک ثبت‌شده:** ارسال `solvedContent` و `lessonContext` (شامل بازه‌های صحیح) به مدل،
«ضدتقلب» را به یک دستور زبانی (R5) تنزل می‌دهد. برای محصول هدف:
**پاسخ درست را هرگز به مدل ندهید**؛ به‌جای آن «کد خطای مفهومی» بدهید.

## ۲. اندازهٔ تقریبی زمینه

| مورد | تخمین | روش |
|---|---|---|
| instructions | ~۱۰۰–۳۰۰ کاراکتر | نمونهٔ درس کدی |
| فایل‌ها | ۲۰۰–۲,۰۰۰ کاراکتر | میانهٔ `content` در محتوا |
| lessonContext | ۵۰۰–۳,۰۰۰ کاراکتر | فایل میانهٔ درس تعاملی |
| سقف عملی مدل | نامعلوم | **UNKNOWN** |

## ۳. طرح پیشنهادی مونتاژ (نسخهٔ امن)

```python
ctx = {
  "concept": concept_id,           # نه متن کامل درس
  "question_stem": stem,           # صورت سؤال
  "learner_answer": sanitize(ans), # پاسخ کاربر
  "error_code": error_code,        # تشخیص، نه کلید
  "attempt_no": n,
  "hint_level": h,
}
```
سپس پرامپت با ۹ قاعده (نسخهٔ فارسی) + `ctx` ساخته می‌شود. هیچ کلید پاسخی در زمینه نیست.
