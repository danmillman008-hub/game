# ۰۱ج — تحلیل کد Native

**کلاس شواهد:** VERIFIED_STATIC (فهرست فایل‌ها) / UNKNOWN (رفتار)

| کتابخانه | ABI | اندازه | نقش تأییدشده | نقش استنباطی |
|---|---|---|---|---|
| `librive-android.so` | arm64-v8a, armeabi-v7a | — | رندر Rive (۹۸۳ کلاس Java/Kotlin همراهش) | انیمیشن زنجیره/پایان فصل |
| `libdatastore_shared_counter.so` | هر دو | — | شمارندهٔ مشترک DataStore | شمارش جلسه/رویداد چندفرایندی |
| `libandroidx.graphics.path.so` | هر دو | — | مسیر گرافیکی Compose | رندر مسیرها |
| `libc++_shared.so` | هر دو | — | NDK runtime | — |
| `libsigner.so` | هر دو | — | نامشخص | احتمالاً امضای درخواست/بسته |
| `libyrf.so` | هر دو | — | نامشخص | نام اختصاصی؛ بدون تحلیل نمادین |

**عدم دسترسی:** `nm`, `readelf`, `objdump`, `ghidra` در محیط موجود نیست ⇒ هیچ ادعایی دربارهٔ
سمبل‌ها، JNI entry points یا الگوریتم درون کتابخانه‌های native مطرح نمی‌شود.

**یافتهٔ مهم (منفی):** منطق درس، تصحیح پاسخ و امتیازدهی در DEX است، نه native. هیچ
`JNI` مرتبط با `lessonparser` مشاهده نشد (بر پایهٔ نبود نام در فهرست کلاس‌ها).
