# screenshots/

No screenshots are included: this analysis was performed **without a running device**
(mission constraint: static analysis only), so any image claiming to show Mimo's UI would be a
fabrication.

What is here instead: the exact measurable facts a designer needs to rebuild the screens —
see `../final/02_SCREENS_AND_VISUAL_SPECIFICATION.md` (states per surface) and
`../final/04_DESIGN_SYSTEM.md` (colours, dimensions, type scale).

To obtain real screenshots legitimately: install the public app on a test device, capture the 24
flows listed in `02`, and store them with the same naming as the section headings
(`02_03_onboarding_motive.png`, …). Runtime capture also answers the 12 questions in
`../final/21_UNKNOWNS_AND_OPEN_QUESTIONS.md`.
