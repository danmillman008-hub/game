# Spec 110 — Design System

## MUST
1. Aeonik family in three cuts (Pro/Mono/Fono) with weight/style mapping via font-family resources.
2. Two separate colour systems: UI palette and editor/highlighting theme.
3. Span-based gap/selection rendering with a partially editable input window.
4. Rive for animation.

## MUST NOT
- Claim hex values, spacing scale or dark-mode support (BLOCKED/unknown).

## GIVEN EVIDENCE
`10_DESIGN_SYSTEM/70..74`.
