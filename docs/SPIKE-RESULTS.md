## ۲) دروازهٔ ۲ و ۳ — تعویض ML Kit و آنچه یاد گرفتیم

**کاری که کردیم:** `play-services-mlkit-barcode-scanning:18.3.1` → `com.google.mlkit:barcode-scanning:17.3.0`
(نسخهٔ باندل‌شده) + حذف متادیتای `com.google.mlkit.vision.DEPENDENCIES` از Manifest.

**نتیجه:** کامپایل سبز. داخل APK:
```
assets/mlkit_barcode_models/barcode_ssd_mobilenet_v1_dmp25_quant.tflite   (390 KB)
lib/arm64-v8a/libbarhopper_v3.so                                        (4.9 MB)
```
یعنی مدل و موتور اسکن **داخل APK** هستند، نه دانلودی.

**اما یک نکتهٔ ظریف که فقط با آزمایش معلوم شد:** تلاش کردم کلاینت نازک Play Services را
از classpath حذف کنم (`exclude`). بیلد شکست:

```
e: BarcodeScannerImp.kt:5:40 Unresolved reference 'BarcodeScanning'.
```

یعنی در این نسخه، کلاس‌های API از همان آرتیفکت GMS می‌آیند. پس **حذف کامل ممکن نیست** و
ادعای «بدون Play Services» فعلاً فقط *محتمل* است، نه اثبات‌شده.

> **پس یک کار باقی مانده:** تست زمان اجرا روی امولاتور بدون GMS (ایمیج `default` نه `google_apis`).
> این تنها راه قطعی است. ~۳۰ دقیقه کار. اگر بگویی، انجامش می‌دهم.

## ۳) دروازهٔ ۴ — اندازهٔ واقعی APK

| نوع | بدون OCR | با OCR تاریخ‌خوان |
|---|---|---|
| **arm64-v8a** (گوشی‌های امروزی) | **14.7 MB** | 34.5 MB |
| armeabi-v7a (گوشی قدیمی) | 13.1 MB | 27.2 MB |
| universal (همه در یک فایل) | 29.6 MB | 87.1 MB |

**چه چیزی این اختلاف را ساخت؟** موتور OCR تاریخ‌خوان (`libmlkit_google_ocr_pipeline.so` = 11 MB
برای هر ABI + مدل‌های tflite + `libtextclassifier3`). این قابلیت در Algidy برای «خواندن تاریخ انقضا از
عکس بسته» است — **ما به آن نیازی نداریم**، چون تاریخ را از GS1 و کاربر می‌گیریم. حذفش کردیم و
هیچ ViewModelی به آن وابسته نبود (فقط در DI ثبت شده بود).

**نتیجهٔ مهم:** بودجهٔ «APK زیر ۲۵MB» با نسخهٔ سبک **قابل تحقق است** (۱۴.۷MB برای arm64).
ولی اگر OCR را نگه داریم، بودجه می‌شکند.

## ۴) دروازهٔ ۵ — فونت وزیرمتن و فارسی/RTL

**فونت:** `Vazirmatn[wght].ttf` نسخهٔ variable (یک فایل، همهٔ وزن‌ها) — **۲۴۱ کیلوبایت**.
جایگزین `GoogleSansFlex` چهار مگابایتی شد. کد تغییر یافته:

```kotlin
private val VazirmatnFontFamily = FontFamily(
    Font(resId = R.font.vazirmatn, weight = FontWeight.Normal,
         variationSettings = FontVariation.Settings(FontVariation.weight(400))),
    ... // 500 / 600 / 700
)
```
(R8 بقیهٔ فونت‌های بلااستفاده — Montserrat×۶ و Poppins×۴ — را هم خودش حذف کرد؛
در نسخهٔ سبک صریحاً پاک شدند.)

**فارسی:** کلید `AppLanguage.PERSIAN("fa")` اضافه شد، پیش‌فرض برنامه فارسی شد،
و ۸۴ رشتهٔ کلیدی ترجمه شد (موجودی، انقضا، خطاها، دسته‌ها، تنظیمات…).

**RTL:** خوشبختانه ساختار از قبل آماده بود:
`android:supportsRtl="true"` · `configChanges="locale|layoutDirection"` · سرویس
`AppLocalesMetadataHolderService` (appcompat per-app locales) · و `MainActivity` که
locale را در زمان اجرا ست می‌کند.

**اثبات از داخل APK ساخته‌شده:**
```
resource string/inventory_title
  ()   "Inventory"
  (fa) "موجودی"
  (vi) "Kho lưu trữ"
```
یعنی منابع فارسی درست بسته‌بندی می‌شوند. چیزی که **نمی‌توانم** اثبات کنم،
ظاهر واقعی روی گوشی است (چیدمان راست‌به‌چپ، برش متن، اعداد).

## ۶) حکم نهایی

**Algidy به‌عنوان نقطهٔ شروع تأیید می‌شود — با سه شرط:**

1. **پایه را بپذیر، ولی «تست‌دار» ندان.** تست‌ها را برای دامنهٔ خودمان از صفر می‌نویسیم.
2. **OCR تاریخ‌خوان را از روز اول حذف کن** (۱۵–۲۰ مگابایت صرفه‌جویی، صفر وابستگی).
3. **قبل از فاز ۳، تست زمان‌اجرا روی امولاتور بدون GMS** تا «اسکنر روی گوشی بدون سرویس گوگل» اثبات شود.

**چه چیزی از این اعتبارسنجی تغییر کرد؟** هیچ‌کدام از تصمیم‌های معماری. فقط یک عدد
(اندازهٔ APK) از «نگرانی» به «حل‌شده» رفت، و یک ادعا (تست‌ها) از «مزیت» به «کار لازم» تبدیل شد.
