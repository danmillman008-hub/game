## ۴) تصریحهای مستقیم کاربر (عیناً حفظ شود)

1. «خروجی گرفتن … اچتیام یکجا یا اپلیکیشن گوشی … در حد کلیک کردن باشد» و
   «مسیر آموزشی و ساختار توکنها و بخش هوش مصنوعی … کاملاً کار کند».
2. «از بعد ساخت این سری بهت اجازه میدم پروتوتایپ رو تغییر بدی دقیقاً منطبق با
   نرمافزار اصلی بسازی … بخش یادگیری رو به خصوص دقیقاً باید شبیه خود اپ بشه …
   پروتوتایپ فعلی هم یه سری نکات داره باید رعایت کنی … صد درصد خودت درک میکنی
   حین انجام» ← **لیست نکردن نکات و نپرسیدن از کاربر**؛ حفظ ۱۰۰٪ یادداشتها.
3. «`Mimo.html` فاجعه است» ← پذیرش و بازسازی، نه دفاع.
4. «ساختار درسنامه و درس و سؤالات رو اصلاً متوجه نشدی … یه نمونهٔ خام
   فرانگشتانی … حتی در پروتوتایپ هم همین مشکل رو داریم» ← پذیرش ریشه و ساخت
   لایهٔ محتوا (`MIMO_CONTENT_MODEL.md`).
5. «کل ریپو رو جوری منظم کن که به هر ایجنتی داده شد دقیقاً بفهمه …» ← این
   مجموعه اسناد `docs/`.
