## ۲. پنل AI مینیمال — مشخصات دقیق

| عنصر | وضعیت | منبع |
|---|---|---|
| هدر میمو: ماسکات ✦ + `ai_tutor_chat_header` + پالس | ✅ | Mimo `coding_keyboard_layout.xml` / رشتههای `ai_tutor_*` |
| **تاریخچه** (یک آیکن 🕘 ← باتمشیت لیست گفتگوها + «گفتگوی تازه») | ✅ تنها گزینهٔ اضافی | `AiAssistant.vue` (History / new conversation), `ChatView.vue` (`/chat/messages`) |
| حبابهای گفتگو (کاربر / دستیار)، RTL | ✅ | پوستهٔ میمو |
| «در حال نوشتن…» + پاسخ جریانی | ✅ | `ChatView.vue` (`ai_delta` / WebSocket) |
| ورودی `ai_tutor_input_placeholder` + دکمهٔ ارسال | ✅ | Mimo (تغییر نکرده) |
| متن کوچک «پاسخها از LearnHarness میآیند · /max» | ✅ | اتصال بکاند |
| داک ۳۲ دکمه، سایدبار `SESSIONS`، `Chains`, `Import notes`, `Knowledge graph`, `TEACH/PRACTICE`, `Dictate`, مدل، `medium`, `Cost`, `Background agents`, `Settings` | ❌ **نمایش داده نمیشوند** | بایگانی در `CATALOGS/LEARNHARNESS_ACTIONS.csv` (ستون `surface`) |

منبع بصری دوم: اسکرینشات پیوستشدهٔ پنل اصلی LH (SHA-256 `514a61671f9e3eb3562905c057fdd132ece6e8dd06df0711d125338a403890e6`، ۱۴۳۶×۱۰۱۲) — همان سادگی «Knowledge graph / What do you want to learn?»، ولی در پوستهٔ میمو و بدون ردیف کنترلها.

### قرارداد رفتاری
- ارسال پیام → حباب کاربر → «در حال نوشتن…» → پاسخ شبیهسازیشده → `/max` در محصول واقعی.
- کلید `Enter` هم ارسال میکند؛ `تاریخچه` لیست گفتگوها را میآورد؛ «گفتگوی تازه» چت را پاک میکند.
- لینک «توضیح این سؤال» در آزمون، `زمینه: <نام آزمون> · سؤال ۳` را به چت تزریق میکند (بدون ارسال پاسخنامه).
- نایت مُد، RTL، `card_enabled/pressed`، شعاع ۱۲dp، فاصلهٔ ۱۶dp — ۰ رنگ تازه.
