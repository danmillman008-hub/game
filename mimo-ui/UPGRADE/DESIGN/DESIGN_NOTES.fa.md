همه در **همان صفحه** با اسکرول دیده میشوند؛ اضافهکردن نوع تازه = یک لیبل + خط `قالب: …` + سه گره، بدون صفحهٔ تازه. ماشینخوان: `../CATALOGS/EXAM_SECTION_TEMPLATES.csv`. چیپهای فیلتر بالا برای جامع/زماندار/تکدرسی/مبحثی/این ماه/تحلیلی/جمع بندی.

**تایمر:** همچنان فقط داخل آزمون (`idle → setting → running ⇄ paused → finished`). نوع `comprehensive` عدد ۲۷۰ ثابت و قفلشده میگیرد؛ بقیه انواع عدد دلخواه ۱–۳۰۰.

## ۴. پاسخنامه — سیاست بر اساس نوع آزمون

| سیاست | انواع | حین آزمون | بعد از اتمام |
|---|---|---|---|
| `during_and_after` | عادی / تکدرسی / مبحثی / درسی / این ماه / شخصیساخته / سریع / دوباره | ✅ «پاسخنامه» (پاسخبرگ، بدون کلید صحیح) | ✅ تستی + تشریحی + تحلیل |
| `during_and_after_analysis` | **تحلیلی** | ✅ | ✅ تحلیل کامل + شبیهسازی |
| `after_only_fixed_time` | **جامع** (۲۷۰ دقیقه ثابت) | ❌ | ✅ تستی + تشریحی + تحلیل |
| `after_only` | جمع بندی / نهایی / دوره | ❌ | ✅ تستی + تشریحی + تحلیل |

دکمهٔ «پاسخنامه» جای «پالت سؤالات» نشست. بعد از اتمام (تایمر صفر / «ثبت پاسخها و پایان» / «اتمام آزمون») پنل نتیجه میآید: درصد، «اگر غلطها نزده میذاشتی»، غلط/نزده، نوع آزمون + دو دکمهٔ **«پاسخنامهٔ تستی»** (کلید گزینهای + `answerKeyVersion`) و **«پاسخنامهٔ تشریحی»** (توضیح گامبهگام، مبحث، تعویض سوال) — «عین یه آزمون آنالیز بشه». ایده از همدرس/هدفپلاس و EPM، فقط الگوی رفتاری، ۰ کپی.
