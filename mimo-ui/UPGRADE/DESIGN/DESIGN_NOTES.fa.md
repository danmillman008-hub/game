## ۲. مشاوره — مشخصات برنامهریز (بخشی که خواستید «خودش بتونه استفاده بکنه»)

**جریان کاربر:**
1. یکی از **۷ قالب هدفپلاس** را بزند → بلوکهای پیشفرض روی هفتۀ جاری مینشینند (هر قالب الگوی متفاوتی دارد: پومودورو ۴۵دقیقهای، دورهٔ فشرده ۱۲۰دقیقهای، روز تعطیل فقط بلوکهای بلند، …).
2. روی `＋` هر روز → باتمشیت «افزودن بلوک مطالعه» (روز، درس، مبحث، ساعت شروع، مدت ۴۵/۶۰/۹۰/۱۲۰).
3. روی `×` هر بلوک → حذف؛ روی «هدف: N ساعت» → باتمشیت ویرایش هدف (۰…۱۶، گام ۰٫۵).
4. نوار پیشرفت هر روز = `دقایق بلوکها / (هدف × ۶۰)`؛ خلاصهٔ هفته و «هدف کل هفته» زنده بهروز میشود.
5. «ذخیرهٔ برنامه» → وضعیت «ذخیره شده ✓» و ماندگاری در مراجعهٔ بعدی؛ «پاک کردن» ریست؛ «خروجی برنامه» یک JSON قابلاستفاده توسط سایر بخشها میدهد.

**قرارداد خروجی (نمونه):**
```json
{
  "version": "konkur-plan-v2",
  "template": "pomodoro",
  "weekStart": "۱۴۰۵/۰۸/۱۲",
  "locale": "fa",
  "goalsHours": [2,2,2,2,2,3,4],
  "blocks": [{"day":"شنبه","subject":"زیستشناسی","topic":"گردش خون","start":"16:00","minutes":45}],
  "totalMinutes": 315,
  "saved": true,
  "noSubscription": true
}
```

**جایی که به بقیهٔ اپ وصل میشود (در فازهای بعد):** `ExamBlueprint` (زمان/تعداد سؤال از همین برنامه)، `XpEvent` (اجرای روزِ برنامه → XP + Streak)، `report_model` (گزارش ۷/۳۰/۹۰ روزه)، `daily_sparks_goal_progress_view` (هدف روزانه)، `leaderboard_*` (رقابت ساعت مطالعه)، `؟` راهنما (الگوی `helpcenter/lessons.json` همدرس).

**حذفشده:** هیچ صفحهٔ اشتراک، سبد خرید، پرداخت، «پرو»، بنر تخفیف، `zarinpal` و `+۱۰ ابزار دیگه` وجود ندارد. درخواست مشاور فقط فرم عملی است.

**زبان بصری:** همان `card_enabled/pressed/disabled/outline`، شعاع ۱۲dp، فاصلهٔ ۱۶dp، تایپوگرافی میمو، باتمشیت `bottom_sheet_content_max_width 496dp`، `lesson_progressbar_height 6dp`. ۰ رنگ/آیکن/کامپوننت تازه.

## ۳. تایمر آزمون — ماشین حالت (فقط داخل آزمون)

| حالت | نمایش | اقدام |
|---|---|---|
| `idle` | chip «تنظیم زمان»، متن «زمان تنظیم نشده» | کلیک → باتمشیت |
| `setting` | باتمشیت عدد + پیشفرضها | «شروع آزمون» |
| `running` | `mm:ss` معکوس، «زمان معکوس در حال اجرا» | توقف / تنظیم مجدد / ثبت پاسخها |
| `paused` | عدد متوقف، دکمه «ادامه» | ادامه با همان باقیمانده |
| `finished` | `۰۰:۰۰` قرمز، بنر «زمان تمام شد — پاسخها خودکار ثبت شدند»، گزینهها قفل | تنظیم مجدد |

منطق نهایی محصول (نه پروتوتایپ): `elapsedRealtime()` مونوتونیک، ذخیرهٔ خودکار هر ۵ ثانیه، ادامه بعد از kill اپ، هشدار ۱۰٪ پایانی با `error_default`، اتمام خودکار و محاسبهٔ درصد. **در هاب آزمون هیچ تایمری وجود ندارد** — نه chip، نه badge زمان، نه شمارش.
