تغییرات v3 (بازخورد جدید)

  • ۱) مشاوره: فعلاً کنار گذاشته شد (PARKED). هیچ صفحه، طراحی یا استفادهای برایش وجود ندارد؛ فقط شواهد RE بایگانی است.
  • ۲) دستیار هوشمند: به چت ساده و مینیمال تبدیل شد: حبابها + ورودی + ارسال + حداکثر یک «تاریخچه». ۳۲ دکمه، سایدبار جلسهها، گراف دانش و ردیف ابزار حذف شدند.
  • ۳) قابلیتهای LH: حذف نشدهاند؛ پشت بکاند /max و لایهٔ نشست باقیاند، فقط دیگر در UI نمایش داده نمیشوند.
  • ۴) آزمون: دقیقاً همان طرح قبلی («عالی») دستنخورده ماند؛ فقط ۳ آپشن جزیی از EPM مستند شد و یک لینک «توضیح سؤال» به چت اضافه شد.

از EPM فقط اینها (همینقدر کم)

  • جابهجایی گزینهها (ضد حفظ پاسخ)
  • پرش به سؤالات نزده
  • تمرین دوبارهٔ فقط غلطها
  • لینک «توضیح این سؤال» ← چت

❌ نیامد: FSRS / واژگان / RAG / FTS / تحلیل پیشرفته / 3D / چاپ A4 — «زیاد بودن امکانات لزوماً به معنی خوب نیست».

ماشین حالت تایمر (بدون تغییر)

  • idle → «تنظیم زمان» (بدون عدد)
  • setting → باتمشیت: عدد + پیشفرضها
  • running → mm:ss معکوس + توقف/ادامه
  • paused → عدد متوقف، رنگ خنثی
  • finished → صفر، قرمز، ثبت خودکار پاسخها
