تغییرات v2 (بازخورد شما)

    
    
      
  • ۱) تایمر: از نوار بالای هاب آزمون حذف شد؛ فقط داخل «اجرای آزمون» است: کلیک ← عدد دقیقه ← شروع ← شمارش معکوس.
    • 
      
  • ۲) دستیار هوشمند: دکمههای واقعی LH از اسکرینشات شما (TEACH/PRACTICE, Chains, Import notes, Dictate, مدل, medium, Knowledge graph, Sessions, Background agents, Settings, Cost) در پوستهٔ میمو جاسازی شدند.
    • 
      
  • ۳) مشاوره: از کارتهای ایستا به برنامهریز هفتگی قابلاستفاده تبدیل شد: ۷ قالب قابلاعمال، افزودن/حذف بلوک، هدف روزانه، ذخیره و خروجی JSON.
    • 
    

    
ماشین حالت تایمر

    
    
      
  • idle → «تنظیم زمان» (بدون عدد)
    • 
      
  • setting → باتمشیت: عدد + پیشفرضها
    • 
      
  • running → mm:ss معکوس + توقف/ادامه
    • 
      
  • paused → عدد متوقف، رنگ خنثی
    • 
      
  • finished → صفر، قرمز، ثبت خودکار پاسخها
    •
