# game — sandbox repo

این مخزن یک فضای کاری شخصی است. مهم‌ترین محتوای فعلی:

## `mimo-re/` — مهندسی معکوس اپلیکیشن Mimo 9.35 (com.getmimo)

گزارش کامل تحلیل ایستای APK در چارچوب متدولوژی [morluto/rea](https://github.com/morluto/rea):

- **`mimo-re/report.html`** — گزارش نهایی (راست‌به‌چپ، قابل ارائه)
- `mimo-re/MIMO-REPORT.md` — همان گزارش به‌صورت Markdown (منبع)
- `mimo-re/data/` — شواهد خام: manifest، فهرست کلاس‌ها و رشته‌های DEX، APIها، طرح‌وارهٔ Room، آمار محتوا، نقشهٔ مسیرها
- `mimo-re/samples/` — نمونهٔ محتوای واقعی (طرح‌وارهٔ درس تعاملی/اجرایی، فیکسچر تست پارسر)
- `mimo-re/tools/` — اسکریپت‌های بازتولید (`analyze_apk.py`, `analyze_content.py`, `build_report_html.py`)

موضوعات پوشش‌داده‌شده: معماری کد (لایه‌ها، مدل داده، APIها)، معماری معنایی و پداگوژیک محتوا
(DSL تعامل، نردبان سختی، تمرین/مرور، اقتصاد انگیزه، معلم AI)، سازوکار ارزیابی و آزمون
(تعاملی/اجرایی/کوییز/چالش)، و لایهٔ مدیریت و آزمایش (Remote Config، آزمایش محتوایی، Developer Menu).

> فایل‌های باینری بزرگ (APK و بخش‌های ZIP) در مخزن نگه داشته نمی‌شوند؛ در گوگل‌درایو هستند و روش بازسازی در `mimo-re/tools/README.md` آمده است.

## `HANDOFF/` — بستهٔ تحویل: از صفر تا ساخت موتور یادگیری آفلاین

این پوشه برای هر عامل/مهندسی است که **فقط همین مخزن** را در اختیار دارد و هیچ تاریخچهٔ گفتگویی ندارد.
هدف: فهم مشخصات استخراج‌شده، ساخت پروژهٔ مستقل `mimo/`، پیاده‌سازی موتور یادگیری آفلاین، و قابل‌ردیابی ماندن
همهٔ تفاوت‌ها و محدودیت‌ها.

- **ورود از اینجا:** `HANDOFF/START_HERE.md` (ترتیب مطالعه، داده‌های ماشین‌خوان، دستورهای بررسی)
- قواعد ساخت: `HANDOFF/AGENT_BRIEF.md`
- مشخصات هنجاری: `HANDOFF/01_…` تا `HANDOFF/09_…`
- نقشهٔ ساخت `mimo/` با گام‌های M0–M6: `HANDOFF/10_BUILD_THE_MIMO_PROJECT.md`
- آزمون‌های پذیرش: `HANDOFF/11_ACCEPTANCE_TESTS.md`
- ثبتی از تفاوت‌ها (۴۵ تصمیم + ۸ افزوده): `HANDOFF/12_DELTA_REGISTER.md`
- فهرست صادقانهٔ نادانسته‌ها: `HANDOFF/13_KNOWN_UNKNOWNS.md`
- ردیابی ادعا ← شاهد: `HANDOFF/14_TRACEABILITY.md`

```bash
python3 HANDOFF/tools/verify_handoff.py     # 10/10 بررسی یکپارچگی (بدون وابستگی)
python3 -m pytest -q HANDOFF/tests          # 54 آزمون بازتولید بردارهای داوری/پیشرفت
```
