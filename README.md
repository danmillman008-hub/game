# کنکور-میمو × لرن‌هارنس

پلتفرم یادگیری تطبیقی کنکور، ساخته‌شده بر پایهٔ نقشهٔ راه جامع
(`comprehensive-software-development-roadmap (2).zip` → `MASTER_AGENT_PLAYBOOK.md`).

این مخزن پیش از این شامل چند پروتوتایپ پراکنده در شاخه‌ها و آرشیوها بود. اکنون یک
اپلیکیشن یکپارچه و قابل اجرا در ریشهٔ مخزن قرار دارد:

- **اپ یادگیری** روی مسیر `/` — پنج تب فارسی، نقشهٔ مسیر گره‌ای، پخش‌کنندهٔ درس شش‌نقشی،
  هاب هفت‌بخشی آزمون، صف مرور FSRS، مربی آفلاین و پروفایل.
- **کنسول نقشهٔ راه** روی مسیر `/blueprint` — ۱۲ فاز وزن‌دار، کالبدشکافی ریپو،
  استودیوی DSL و پرامپت مادر.
- **هستهٔ خالص دامنه** در `src/core` — بدون DOM و بدون وابستگی به سرور.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # ۵۵ تست: گریدر، الگوریتم‌ها، محتوا، ماشین حالت، جریان UI
npm run typecheck
npm run lint
npm run build
```

## چه چیزی پیاده‌سازی شده است؟

### ۱) محتوا: ۱۸ ریزدرس واقعی، بدون متن دمو

| درس | فصل‌ها | ریزدرس | تست |
|---|---|---|---|
| زیست‌شناسی ۳ | ۳ | ۸ | ۱۶ |
| شیمی ۳ | ۲ | ۵ | ۱۰ |
| فیزیک ۳ | ۲ | ۵ | ۱۰ |

هر ریزدرس از یک «سید ساختاریافته» (`src/core/content/lessons-*.ts`) کامپایل می‌شود و
دقیقاً شش نقش میمو را تولید می‌کند:

`hook (concept_bite) → check (guided_cloze) → feedback (trap_detector) → explain (token_assembly) → practice (konkur_test) → recap (summary_recap)`

هیچ متن دموی چیدمان خط و هیچ سؤال تصادفی هش‌پایه‌ای در محتوا نیست. نگاشت درس به
`curriculumId` صریح است و هر بلوک `sourceRef` دارد.

### ۲) هستهٔ دامنه (`src/core`)

- **نرمال‌ساز فارسی** (`text/normalize.ts`): یکسان‌سازی ی/ك عربی، حذف نیم‌فاصله در کلید
  تطبیق، ارقام فارسی/عربی، اعراب و کاراکترهای صفرعرض — بستن `Q-44`.
- **گریدر سه‌حالته** (`text/grade.ts`): `CORRECT` / `PARTIAL` / `INCORRECT` با تشخیص علت
  (`ZWNJ`، `ARABIC_GLYPH`، `DIGITS`، ...) و پیام آموزشی فارسی؛ به‌همراه گریدر قید‌محور که
  «همه ← برخی» را به‌عنوان تلهٔ طراح می‌شناسد.
- **گرامر DSL میمو** (`dsl/parse.ts`): پارسر تحمل‌پذیر ۲۷ تگ + ارزیابی دروازهٔ سه‌حالتهٔ
  `visible-if`.
- **KST** (`algorithms/kst.ts`): گراف پیش‌نیاز، بستار متعدی، حاشیهٔ بیرونی/درونی دانش و
  انتخاب قدم بعدی.
- **BKT کالیبره** (`algorithms/bkt.ts`): تفکیک پاسخ مستقل (`unaided`) از پاسخ با راهنما
  (`aided`) با `pGuess` متفاوت.
- **FSRS-5** (`algorithms/fsrs.ts`): ۱۹ وزن پیش‌فرض، زمان‌بندی کارت، قابلیت یادآوری،
  پیش‌بینی صف مرور ۷ روزه.
- **کنترلر باند جریان** (`algorithms/flow.ts`): نگه‌داشتن دقت پنجرهٔ اخیر روی ۷۰–۸۵٪.
- **مربی لرن‌هارنس** (`harness/engine.ts`): چهار فاز Measure → Plan → Teach → Practice،
  گره‌خورده به گراف گزاره‌های کتاب (ضدتوهم).
- **ماشین حالت یادگیرنده** (`state/learner.ts`): لاگ افزودنی، قوانین `ADD-03`/`ADD-04`،
  کیف پول، استریک و کارت‌های مرور.

### ۳) تجربهٔ یادگیری (`src/components/app`)

- **نقشهٔ مسیر**: گره‌های ۸۲ پیکسلی روی مسیر منحنی، قفل/در جریان/تسلط، ستاره، درصد تسلط
  هر درس و انتخابگر سه درس.
- **پخش‌کنندهٔ درس**: نوار پیشرفت ۶ پیکسلی، زمان‌سنج نقش‌ها، چهار رندرر تعاملی
  (جای خالی، چیدمان توکن با تله، شکار تله، تست چهارگزینه‌ای) و پنل بازخورد.
- **هاب آزمون**: هفت بخش (تشخیصی، فصل، هدفمند، زمان‌دار، اشتباهات، بانک تست، شبیه‌ساز ۲۷۰
  دقیقه‌ای)، نمرهٔ منفی ⅓، پاسخ‌برگ جدا از پاسخنامهٔ تشریحی، ذخیرهٔ خودکار اشتباه‌ها در FSRS.
- **صف مرور**: نمودار پیش‌بینی ۷ روزه، کارت‌ها با نسبت قابلیت یادآوری و چهار دکمهٔ
  زمان‌بندی.
- **آمار و پروفایل**: تسلط، دقت مستقل/با راهنما، باند جریان، توصیهٔ KST، خروجی/بازیابی JSON،
  پوستهٔ روز/شب.

### ۴) سرور

مسیرهای `src/app/api`:

| مسیر | کار |
|---|---|
| `GET /api/health` | شش بررسی سلامت موتور (توالی نقش‌ها، گاردریل، DAG، DSL) |
| `GET /api/blueprint/state` | وضعیت ۱۲ فاز + کالبدشکافی + پرامپت مادر |
| `PATCH /api/blueprint/phase` | به‌روزرسانی وضعیت فاز/تسک‌ها |
| `POST /api/blueprint/compile-lesson` | کامپایل متن کتاب به بستهٔ شش‌نقشی |
| `POST /api/harness` | دروازهٔ LearnHarness (آفلاین؛ با `OPENAI_API_KEY` پروکسی LLM) |

کنسول نقشهٔ راه روی یک فروشگاه JSON پایدار در `.data/` اجرا می‌شود تا بدون هیچ سرویس
بیرونی کار کند. اسکیمای Drizzle/PostgreSQL در `src/db/schema.ts` هدف تولید باقی می‌ماند.

## ساختار پوشه‌ها

```
src/
  app/            مسیرها (اپ، کنسول، APIها، manifest، icon)
  components/
    app/          پوستهٔ یادگیرنده: مسیر، درس، تمرین، مربی، آمار، پروفایل
    ui/kit.tsx    اجزای پایه (کارت، دکمه، مودال، حلقه، جرقه)
  core/           لایهٔ ۱: دامنهٔ خالص (بدون DOM)
    text/ dsl/ algorithms/ harness/ pedagogy/ content/ exam/ state/
  lib/            داده‌های کنسول نقشهٔ راه و کامپایلر استودیو
  server/         فروشگاه پایدار کنسول
  db/schema.ts    اسکیمای تولید (Drizzle/PostgreSQL)
docs/             یادداشت‌های پیاده‌سازی و نگاشت فازها
```
