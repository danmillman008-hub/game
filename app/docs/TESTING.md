# تستها و پذیرش

```bash
cd app
npm test          # ۴۳ تست، ۰ خطا
npm run verify    # بررسی استاتیک یکپارچگی طرح (بدون وابستگی)
```

| فایل | تعداد | پوشش |

| `tests/fidelity.test.mjs` | ۸ | هش مبدأ، کپی بایتبهبایت CSS / مارکاپ گوشی / دادهها، درج عینی در `index.html`، ۵ تب دقیق و نبود «مکس»، ۱۳ صفحهٔ تأییدشده، افزودهبودن `motion.css`، `PROVENANCE.json` |

## مهمترین تست: اجرا، گشتزنی، تغییر وضعیت، تمرین، آزمون، ریاستارت

`tests/acceptance.test.mjs` → «restart recovery» دقیقاً همان سناریوی درخواستشده
را روی **DOM واقعی** انجام میدهد:

1. اپلیکیشن بوت میشود؛ تم شب روشن، مسیر برنامهمحور انتخاب و فعال، یک درس
   تکمیل، یک نشست بانک سؤال ثبت، یک آزمون پاسخ داده و «خروج و ذخیره» میشود،
   سپس صفحهٔ `select-path` باز میماند.
2. `snapshot()` محتوای واقعی `localStorage` گرفته میشود و JSDOM بسته میشود.
3. JSDOM **کاملاً تازهای** با همان snapshot بهعنوان seed ساخته میشود (بستن/باز
   کردن مجدد)، و بررسی میشود: تم شب دوباره اعمال شده، مسیر و برنامه، ردیف
   پیشرفت درس، نشست تمرین، آزمون ذخیرهشده، آخرین صفحه، نوار «ادامهٔ آزمون»،
   و وضعیت گرههای `done/open` همگی برگشتهاند.
4. کلیک «ادامهٔ آزمون» وارد `exam-run` میشود و اسنپشات مصرف میشود.

سایر تستهای پذیرش:

- **گشتزنی کامل**: تکتک ۱۵ صفحه (۱۳ تأییدشده + ۲ تازه) نمایش داده میشوند،
  دقیقاً یک صفحه فعال است، و آخرین صفحه/تب ذخیره میشود؛ پنج تب به صفحات
  ورودی مصوب خود میروند.
- **یادگیری**: انتخاب مسیر مستقیم، مودال فصل، صفحهٔ درس، تکمیل درس →
  `LessonProgress` با `inQueue/publishSetVersion=753`، تغییر گرهٔ بعدی به `open`.
- **تمرین**: ورودی بانک سؤال، فیلتر درسی، انتخاب گزینه، ثبت نشست، و همچنین
  تمرین مبحث جداگانهای که پروتوتایپ دارد.
- **آزمون**: هاب (سطح وضعیت قابل مشاهده) → اجرا → چیپ تایمر/شروع → پاسخ → بررسی/ادامه → خروج و ذخیره
  → پاسخبرگ/ثبت → کارنامه؛ وضعیت `running / paused / finished` و پاک شدن
  اسنپشات پس از اتمام.
- **برنامهمحور**: ۵ مرحله، انتخاب برنامه، فعالسازی، انتقال مجاز، و برچسب
  صریح «دادهٔ آزمایشی / مراحل رزروشده».
- **پروفایل/امتیازها/AI**: چرخدنده، تم، RTL، هدف روزانه، سه نمای لیدربورد،
  ثبت محلی پیام گفتگو.
- **آفلاین**: اسکن منبع برای نبود `fetch(` و `new XMLHttpRequest/WebSocket`.

## تست محیط اجرا (سرور زنده)

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3000/
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3000/src/app.js
```

همهٔ ۱۴ مسیر استاتیک `200` میدهند و درخواست `../..` مسدود است. سرور روی
`0.0.0.0:3000` برای پیشنمایش زنده بالا میآید و هیچ allowlist میزبان/Origin ندارد.

## تستهای خروجی یککلیکه

`tests/output.test.mjs` (۷ تست) فایل `dist/Mimo.html` را با `runScripts:
'dangerously'` در jsdom از **`https://` و `file://`** بوت میکند، مسیر آموزشی
(۱۸۰ درس، بازشدن ترتیبی، پاسخ و پاداش)، هر سه معنای توکنها، چهار فاز استودیوی
AI، و **دوربرگردان خودخروجی** (فایل صادرشده بایتبهبایت همان فایل است و دوباره
بوت میشود) را بررسی مینماید.

`tools/verify_output.py` (۴۵ بررسی استاتیک) نبود منابع خارجی، نبود
`fetch/XHR/WebSocket/ESM`، درستی base64 درونجاسازی، manifest/SW/آیکونهای PNG،
سلامت ZIP و انطباق hashهای `BUILD_MANIFEST.json` را تأیید میکند.

```bash
cd app && npm test && npm run verify
python3 app/tools/validate_content.py app/content/STARTER_PACKAGE.json
```
