# میمو · اپلیکیشن آفلاین و مستقل

اپلیکیشن واقعی، قابلاجرا و کاملاً آفلاین که **از روی پروتوتایپ نهایی تأییدشدهٔ `v12.5-fa`**
(`mimo-ui/UPGRADE/DESIGN/index.html`، SHA `c356068d…`) ساخته شده است. طراحی تغییر نکرده؛
کد از نو معماری شده است.

> این یک پیادهسازی مستقل است، نه شبیهسازی سرور میمو. `SERVER CONFIRMED=0`؛ هیچ
> درخواست شبکهای، حساب کاربری، توکن یا پاسخ سروری وجود ندارد.

## اجرا

هیچ وابستگی زمان اجرا وجود ندارد (فقط Node.js ≥ 18):

```bash
cd app
npm start
# → http://localhost:3000  (سرور روی 0.0.0.0:3000 برای پیشنمایش زنده)
```

همچنین `app/index.html` خودکفاست و بدون سرور هم (با `file://`) باز میشود؛ در حالت
`http(s)` یک Service Worker پوسته را کش میکند تا بعد از قطع کامل شبکه هم بالا بیاید.

برای تستها (`jsdom` تنها وابستگی dev است):

```bash
cd app
npm install     # فقط بار اول؛ node_modules در گیت نیست
npm test        # ۲۴ تست
npm run verify  # بررسی یکپارچگی استاتیک طرح نهایی
```

## ناوبری محصول

نوار پایین **دقیقاً ۵ تب پروتوتایپ نهایی** است (تب «مکس» وجود ندارد؛ آن مورد اشتباه تایپی
بود و هرگز اضافه نشده است):

| تب | فارسی | صفحهٔ ورودی |
|---|---|---|
| Learn | یادگیری | `learn` (مسیر قوسدار) |
| Practice | تمرین | `exam-hub` |
| AI | هوش مصنوعی | `ai` |
| Leaderboard | امتیازها | `leaderboard` |
| Profile | پروفایل | `profile` |

### سه مسیر یادگیری

1. **یادگیری مستقیم** — از تب یادگیری یا چیپ «یادگیری مستقیم» در صفحهٔ «انتخاب مسیر»؛
   بدون آزمون ورودی وارد مسیر، فصلها، درسها و صفحهٔ درس میشوید. گرهها وضعیت
   `انجامشده / باز / قفل` دارند و با تکمیل درس، محلی باز میشوند.
2. **آزمون** — چیپ «آزمون» یا تب تمرین → هاب ۷ بخش آزمون → اجرای آزمون (تایمر،
   پاسخگویی، پاسخبرگ، پاسخنامه، پرچم، خروج و ذخیره) → کارنامه و وضعیت آزمون.
3. **مسیر یادگیری برنامهمحور (Study Plan)** — صفحهٔ اختصاصی با انتخاب برنامه (دهم /
   یازدهم / دوازدهم)، وضعیت گامها و ساختار رزروشدهٔ «آزمون اولیه ← رفع اشکال ←
   آزمون نهایی ← پایان». مراحل رزروشده **اجرا نمیشوند** و صادقانه بهعنوان ساختار
   آینده علامت خوردهاند.

### بخشهای دیگر

- **بانک سؤال / تمرین** (`Practice ← ＋ مرور و تمرین`): فیلتر درسی، سؤالهای نمونهٔ
  موجود در خود پروتوتایپ، همان کامپوننت پاسخگویی آزمون، بدون محدودیت زمان،
  و ذخیرهٔ نشست تمرینی.
- **پروفایل**: چرخدنده → تنظیمات (حالت شب، آینهٔ RTL، صدا، بازخورد لمسی، کاهش
  انیمیشن، هدف روزانه، خروجی JSON، بازنشانی).
- **امتیازها**: نماهای «این هفته / کلی / بدون داده» با ردیفهای آزمایشی محلی.
- **هوش مصنوعی**: همان سطح پروتوتایپ؛ پیامها فقط بهصورت محلی ثبت میشوند،
  معلم هوش مصنوعی یا پاسخ شبکهای ساخته نشده است.

## وضعیت ذخیره میشود

همهچیز در `localStorage` با کلید `mimo.offline.app.v1` و اسکیمای نسخهدار (`v1`)
ذخیره میشود: تنظیمات، مسیر و برنامه، ردیفهای پیشرفت درس (همان شکل ۱۱فیلدی
`LessonProgress` مستندشده در M09)، آزمون ذخیرهشده، نتایج، نشستهای تمرینی،
گفتگو، آخرین صفحه و تب، و صف فرستادن محلی. بستن و باز کردن مجدد اپلیکیشن،
همهٔ اینها را بازیابی میکند (تست پذیرش مربوطه را ببینید).

## ساختار پوشهها

```
app/
├── index.html                 # پوستهٔ محصول؛ مارکاپ گوشی عیناً از پروتوتایپ درج شده
├── manifest.webmanifest       # PWA ی آفلاین
├── sw.js                      # کش پوسته (network-first + fallback آفلاین)
├── server.js                  # سرور استاتیک بدون وابستگی (0.0.0.0)
├── assets/
│   ├── proto.css              # کپی بایتبهبایت CSS تأییدشده
│   ├── phone.html             # کپی بایتبهبایت مارکاپ گوشی (۱۳ صفحه + ۵ تب)
│   ├── proto-data.js          # کپی بایتبهبایت GEO/LEARN/NODE/KONKUR
│   ├── proto-ui.js            # کپی کاری رندرر پروتوتایپ + ۶ وصلهٔ مستند
│   ├── motion.css             # فقط انیمیشن/ترنزیشن افزوده؛ هیچ رنگ/فونت تازهای ندارد
│   └── PROVENANCE.json        # هش مبدأ و هش همهٔ داراییها
├── src/                       # کد بازنویسیشدهٔ محصول (ES modules)
│   ├── app.js                 # کنترلر، چرخهٔ حیات، واگذاری رویدادها
│   ├── store.js               # ذخیرهسازی آفلاین، اسکیما، مهاجرت، بازیابی
│   ├── engine.js              # منطق خالص (فرمولهای تأییدشدهٔ M09 + قواعد مستقل)
│   ├── fixtures.js            # دادههای آزمایشی، جدا از اسکیمای محتوای نهایی
│   ├── routes.js              # سه مسیر + ماشین وضعیت برنامهٔ مطالعاتی
│   └── views.js               # صفحات جدید با همان کامپوننتهای تأییدشده
├── tools/                     # استخراج/ساخت/راستیآزمایی (منبع طرح دستنخورده میماند)
├── tests/                     # ۲۴ تست وفاداری، واحد و پذیرش (jsdom)
└── docs/                      # معماری، توسعه، تست
```

## محدودیتهای صادقانه

- محتوا (سرفصل، سؤال، توضیح، PDF، معلم AI) **تولید نشده**؛ فقط دادههای نمونهٔ
  موجود در خود پروتوتایپ و برچسبهای خنثی استفاده شدهاند.
- رتبهبندی، امتیازدهی، پاداش و سیاست قفل، قواعد **مستقل محلی**اند و بهعنوان
  رفتار قطعی میمو معرفی نمیشوند (M09 فرمولهای سروری را تأیید نکرده است).
- رندر پیکسلی در مرورگر واقعی با اسکرینشات تأیید نشده (محیط فاقد مرورگر است)؛
  وفاداری با مقایسهٔ بایتبهبایت CSS/مارکاپ/داده + تست DOM در jsdom سنجیده شده است.
