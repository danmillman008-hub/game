# راهنمای پروکسی محلی — رفع خطای Failed to fetch

## چرا لازم است؟

گزارش تشخیصی نشان داد: شبکه شما به سرور Mivi وصل است، ولی سرور هدر CORS
نمی‌دهد و هیچ پروکسی عمومی رایگانی درخواست‌های POST را عبور نمی‌دهد. تنها راه
مطمئن، یک پل محلی بین مرورگر و سرور است. دو گزینه دارید:

---

## گزینه ۱ — پروکسی ویندوزی تک‌فایل (پیشنهادی، بدون نصب هیچ چیزی)

ویندوز ۱۰ خودش PowerShell و .NET داخلی دارد؛ پس نه به پایتون نیاز دارید نه
به چیز دیگر.

۱. فایل **`mivi-proxy-windows.bat`** را از مخزن دانلود کنید (یا از داخل خود
اپ وب، دکمه «⬇️ پروکسی ویندوز»).
۲. روی فایل دابل‌کلیک کنید.
۳. اگر پنجره آبی **Windows SmartScreen** باز شد:
   - روی **More info / اطلاعات بیشتر** کلیک کنید
   - بعد **Run anyway / اجرا به هر حال**
۴. وقتی این پیغام سبز را دیدید یعنی آماده است:
   ```
   Mivi CORS proxy running: http://localhost:8770/
   ```
۵. **این پنجره مشکی را نبندید.** به مرورگر برگردید — حالت اتصال خودکار روی
   «پروکسی محلی» است — و «تست اتصال» و بعد «تولید ویدیو» را بزنید.

برای توقف، همان پنجره را ببندید یا Ctrl+C بزنید.

---

## گزینه ۲ — پروکسی پایتون (مک / لینوکس / ویندوز دارای پایتون)

### نصب پایتون (اگر ندارید)

- **ویندوز:** از https://www.python.org/downloads/ نصب کنید و هنگام نصب تیک
  **Add python.exe to PATH** را بزنید.
- **مک:** `brew install python`
- **لینوکس:** معمولاً از قبل هست (`python3 --version`).

### اجرا

`proxy.py` را که از داخل اپ دانلود می‌شود در یک پوشه بگذارید و در همان پوشه
ترمینال/CMD باز کنید:

- **ویندوز:** در نوار آدرس File Explorer بنویسید `cmd` و Enter، بعد
  `py proxy.py` (یا `python proxy.py`)
- **مک / لینوکس:** `python3 proxy.py`

پیغام درست:
```
Mivi CORS proxy running: http://localhost:8770/proxy?u=<url>
```
پنجره را تا پایان ساخت ویدیو باز نگه دارید.

## عیب‌یابی سریع

| خطا | علت و راه‌حل |
|---|---|
| **This app can't run on your PC / «این فایل اجرا نمی‌شود»** | احتمالاً ویندوز فایل را با پسوند `.txt` ذخیره کرده. در Explorer تیک «File name extensions» را بزنید و مطمئن شوید نام دقیق فایل `mivi-proxy-windows.bat` است (نه `.bat.txt`). نسخه جدید bat هنگام اجرا این مورد را خودش با پیغام واضح تشخیص می‌دهد |
| SmartScreen جلوی bat را گرفت | اطلاعات بیشتر → اجرا به هر حال؛ یا راست‌کلیک روی فایل → Properties → تیک **Unblock** → OK |
| آنتی‌ویروس فایل را قرنطینه کرد | فایل فقط یک پروکسی لوکال است؛ از قرنطینه Restore کنید یا به Exclusions اضافه کنید |
| `[ERROR] Could not start on port 8770` | یک نمونه دیگر (یا پنجره قدیمی‌تر پروکسی) پورت را اشغال کرده؛ پنجره قبلی را ببندید و دوباره اجرا کنید |
| `python not found` | پایتون نصب نیست یا تیک PATH زده نشده — از گزینه ۱ (bat) استفاده کنید |
| تست اتصال سبز شد ولی تولید ویدیو خطا داد | متن خام پاسخ سرور در «گزارش مراحل» ثبت می‌شود؛ همان را ارسال کنید |
| مرورگر هشدار اتصال به localhost داد | localhost امن است؛ اجازه دهید |
| پنجره بلافاصله بسته شد | cmd باز کنید و bat را از داخل آن اجرا کنید تا پیغام خطا بماند |

> نسخه جدید `mivi-proxy-windows.bat` دیگر از تکنیک پلی‌گلات `<# :` استفاده
> نمی‌کند (همان ساختاری که روی بعضی ویندوزها باعث خطای اجرا می‌شد). به‌جایش
> یک هدر سادهٔ batch، بخش PowerShell را با نشانگر `PS_PAYLOAD_START` از خود
> فایل استخراج و با `-ExecutionPolicy Bypass` اجرا می‌کند. فایل باید حتماً
> **CRLF، ASCII و بدون BOM** باشد — هر سه مورد هنگام ساخت بررسی شده‌اند و دکمه
> دانلود داخل اپ هم خروجی را خودکار به CRLF تبدیل می‌کند.

## نکته امنیتی فایل

کل ترافیک فقط به دامنه‌های `ufotosoft.com`، `videomate.cc` و `wiseoel.com`
فوروارد می‌شود (allow-list داخل هر دو پروکسی) و چیزی روی سیستم نصب نمی‌شود.
