# راهنمای اجرای proxy.py (رفع خطای Failed to fetch)

اپ وب بدون یک پل محلی نمی‌تواند مستقیم با سرور Mivi حرف بزند (مرورگر به‌خاطر CORS
جلوگیری می‌کند). فایل `proxy.py` که از داخل خود اپ دانلود می‌شود همین پل است و
به هیچ نصب پکیجی نیاز ندارد — فقط خود پایتون.

## ۱) نصب پایتون (اگر ندارید)

- **ویندوز:** از https://www.python.org/downloads/ نصب کنید و هنگام نصب تیک
  **Add python.exe to PATH** را بزنید.
- **مک:** `brew install python` یا نصب‌کننده همان سایت.
- **لینوکس:** معمولاً از قبل هست (`python3 --version` را چک کنید).

## ۲) اجرای پروکسی

`proxy.py` را که از داخل اپ (دکمه «ساخت و دانلود فایل پروکسی محلی») دانلود کردید،
در یک پوشه بگذارید و در همان پوشه ترمینال/CMD باز کنید:

- **ویندوز:** داخل پوشه، در نوار آدرس File Explorer بنویسید `cmd` و Enter، بعد:
  ```
  py proxy.py
  ```
  اگر `py` شناخته نشد: `python proxy.py`
- **مک / لینوکس:**
  ```
  python3 proxy.py
  ```

پیغام درست این است:
```
Mivi CORS proxy running: http://localhost:8770/proxy?u=<url>
```
این پنجره را **نبندید** — تا وقتی ویدیو می‌سازید باید باز بماند.

## ۳) استفاده در اپ

در فایل HTML، حالت اتصال را روی **«پروکسی محلی»** بگذارید (دکمه دانلود proxy.py
به‌صورت خودکار همین کار را می‌کند) و دکمه «تست اتصال» را بزنید. اگر خط سبز
«عملکرد proxy.py روی 8770 ... آماده است» دیدید، تولید ویدیو کار خواهد کرد.

## عیب‌یابی سریع

| خطا | علت و راه‌حل |
|---|---|
| `python not found` در ویندوز | پایتون نصب نیست یا تیک PATH زده نشده؛ دوباره نصب کنید |
| `Address already in use` / پورت ۸۷۷۰ اشغال | یک نمونه دیگر باز است؛ یا در فایل `proxy.py` مقدار `PORT = 8770` را به ۸۷۷۱ تغییر دهید و در تنظیمات اپ آدرس پروکسی سفارشی را با پورت جدید وارد کنید |
| تست اتصال همچنان Failed است ولی ترمینال پیغام آماده‌باش دارد | مرورگر را کامل ببندید و دوباره فایل HTML را باز کنید |
| مرورگر هشدار اتصال ناامن به localhost داد | localhost امن تلقی می‌شود؛ اجازه دهید |
